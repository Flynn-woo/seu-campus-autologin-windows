# 更新记录

## 0.1.1 - 2026-09-08

- 修复仅在 Windows 登录时检查一次、重连及唤醒后不再自动认证的问题。
- 增加网络与唤醒事件触发，每两分钟补查，后台等待网关最长两分钟。
- 事件注册受限时回退到周期任务；任务计划不可用时使用启动项持续监测。
- 提供独立无窗口程序；升级保留已有凭据，清理重复启动项并停止旧后台进程。
- 网络等待期限不再意外取消第二次认证；网关结果页已认证时停止重试。
- 明确拒绝认证后暂停后续后台提交，重新配置凭据后恢复。
- 修正 64 位 Windows 互斥量句柄类型；测试和开始菜单入口保留结果窗口。
- 脱敏诊断增加实际任务触发器、启用状态、最近运行时间和结果码。

本地验证和未覆盖场景见 [本次修复验证](FIX-0.1.1.md)。

## 0.1.0 - 2026-08-12

- 支持固定门户 `http://10.9.10.100/` 的自动认证。
- 使用 Windows Credential Manager 保存凭据。
- 支持任务计划、手动测试、脱敏诊断与完整卸载。
- 增加固定主机允许列表、联网误判保护和滚动日志。
- 提供免 Python 的 Windows 文件夹版构建流程。
